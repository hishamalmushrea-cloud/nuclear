# 🔬 المختبرات الافتراضية (`sims/`)

**الفكرة:** بدل أن تقرأ عن التجربة، **تجريها**. كل مختبر يعطيك بيانات فيها
ضجيج إحصائي واقعي، ويُخفي الحقيقة عنك حتى تقيسها، ثم يكشفها ويشرح خطأك.

> **أمان:** لا يوجد أي مصدر مشعّ ولا أي جهاز حقيقي. كل ما هنا أرقام مولّدة
> إحصائياً. أي عمل بمصدر حقيقي يحتاج مختبراً مرخّصاً ومسؤول وقاية معتمد.

## التشغيل

```bash
python3 -m sims              # قائمة المختبرات
python3 sims/01_decay_lab.py # تشغيل مختبر واحد مباشرة
```

## ماذا تفعل بعد كل مختبر؟

1. سجّل ما حدث في `progress/notebook-template.md` (انسخه إلى ملف جديد).
2. أعد التشغيل ببذرة مختلفة: هل تتغير نتيجتك؟ هذا هو «عدم اليقين» الذي يجب أن تعتاده.
3. غيّر متغيراً واحداً فقط في كل مرة (زمن القياس، المسافة، السماكة، التفاعلية) —
   هذه أول قاعدة في تصميم التجارب (`res.design`).
4. سجّل إتقانك: `python3 tools/progress.py set nuc.halflife L2 78`.
