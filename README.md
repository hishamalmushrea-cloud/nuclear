# 🧭 nuclear — الخريطة الكبرى للعلوم والتكنولوجيا النووية

مستودع يحتوي **نظام تعليم وبحث نووي متعدد التخصصات**: خريطة معرفية حيّة (رسم موجّه
غير دوري من 244 موضوعاً و512 رابط شرط-مسبق)، ومنهج متدرّج من الصفر إلى مستوى الباحث،
ومسارات تخصص، ومشاريع واختبارات، وأدوات برمجية لتحديث الخريطة وتتبّع التقدّم.

> هذا المستودع **ليس مقالاً**، بل «نظام تشغيل» لمشروع تعلّم طويل الأمد.

---

## 🚀 ابدأ من هنا

1. [`MAP/00-index.md`](MAP/00-index.md) — الفهرس الشامل وطريقة استخدام النظام.
2. [`MAP/01-grand-tree.md`](MAP/01-grand-tree.md) — الشجرة الكبرى (مولّدة آلياً).
3. [`MAP/16-zero-to-researcher.md`](MAP/16-zero-to-researcher.md) — المسار من الصفر إلى الباحث.
4. [`site/index.html`](site/index.html) — عارض تفاعلي للرسم المعرفي (شغّله: `python3 -m http.server 8000`).

## 📁 بنية المستودع

```
MAP/         الوثائق التأليفية والمولّدة (الخريطة، المنهج، المسارات، المصادر، المشاريع…)
graph/       knowledge_graph.json + edges.csv  (البيانات القابلة لإعادة الاستخدام)
tools/kg/    العقد المعرفية (ملفات nodes_*.py) + المخطط + سجل المصادر
tools/       build.py (بناء/تحقق/توليد) · progress.py (ملف التقدّم والتقييم)
progress/    ملف تقدّم المتعلّم + دفتر الباحث + تقارير الفجوات
site/        عارض الويب التفاعلي للرسم
```

## ⚙️ التشغيل

```bash
python3 tools/build.py            # تحقّق + توليد graph/ و MAP/01..04 و site/graph_data.json
python3 tools/build.py --check    # تحقّق فقط
python3 tools/progress.py show    # حالة ملف التقدّم
python3 tools/progress.py set nuc.fission L2 78   # تحديث إتقان موضوع
python3 tools/progress.py report  # تقرير فجوات + الجاهزية للانتقال
python3 -m http.server 8000       # عرض site/index.html على المنفذ 8000
```

## 🔒 حدود المحتوى (X.31 / X.32)

يغطّي هذا المستودع الفيزياء والكيمياء والهندسة النووية والمفاعلات والإشعاع والحماية
والسلامة والتطبيقات والتاريخ والتحليل الاستراتيجي بعمق أكاديمي كامل.
أما ما يتعلّق بتطوير أو تصنيع أو تحسين الأسلحة النووية أو الأجهزة المتفجّرة أو الحصول
غير المشروع على مواد نووية: **لا يوجد فيه خطوات تنفيذية ولا تصاميم ولا معلمات تشغيلية**،
ويعالَج فقط من زوايا الفيزياء العامة والتاريخ والآثار والسلامة والأمن وعدم الانتشار.
