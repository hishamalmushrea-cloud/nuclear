# الوحدة 1.1 — الأسس واللوغاريتمات والتدوين العلمي

## 1) ما هو؟
ثلاث أدوات رياضية تتكرر في كل صفحة من كتاب نووي:
- **الأسس** (10⁻¹⁵، 2ⁿ، eˣ)
- **اللوغاريتمات** (العملية العكسية للأس)
- **التدوين العلمي** (3.7×10¹⁰ بدل 37000000000)

## 2) لماذا يهم؟
لأن **قانون التحلل نفسه أُسّي**: `N(t) = N₀ e^(−λt)`.
بدون فهم الأس واللوغاريتم لا يمكنك حساب:
عمر النصف، زمن تخزين نفايات، عدد طبقات التدريع، ولا قراءة أي رسم لوغاريتمي
(وهو الشكل المعتاد لرسم المقاطع العرضية والأطياف).

## 3) المتطلبات السابقة
الوحدة 0.1 (الوحدات والتدوين العلمي) — `math.pre`.

## 4) الفكرة الأساسية
الأس يجيب عن «كم مرة نضرب؟»، واللوغاريتم يجيب عن السؤال المعاكس:
**«ما الأُسّ الذي يعطيني هذا الرقم؟»**

## 5) شرح مبسط
تخيّل ورقة تطويها نصفين كل مرة: بعد 1 طية = 2 طبقة، بعد 2 = 4، بعد 3 = 8…
النمو **أُسّي**. والسؤال المعاكس: «لدي 128 طبقة، كم طية؟» = 7،
وهذا بالضبط معنى `log₂(128) = 7`.
الاضمحلال الإشعاعي هو نفسه ولكن بالعكس: **تنقسم الكمية نصفين كل عمر نصف**.

## 6) شرح جامعي
قوانين الأسس:
```
a^m · a^n = a^(m+n)          a^m / a^n = a^(m−n)
(a^m)^n = a^(mn)             a^0 = 1              a^(−n) = 1/a^n
```
قوانين اللوغاريتمات:
```
log(ab)  = log a + log b     log(a/b) = log a − log b
log(a^n) = n·log a           log_a(a) = 1
```
بين اللوغاريتم العشري والطبيعي:
```
ln x = 2.3026 · log₁₀x       log₁₀x = ln x / 2.3026
```
الرقم `e ≈ 2.71828`، و`ln` هو اللوغاريتم أساسه e — لماذا يظهر في الطبيعة؟
لأن **معدل التغير يتناسب مع الكمية المتبقية**، وحل هذه المعادلة هو الأُسّ الطبيعي.

## 7) المعادلات الأساسية
- `N(t) = N₀ · e^(−λt)` — قانون التحلل.
- `T₁/₂ = ln2 / λ` ومنه `λ = 0.693 / T₁/₂`.
- للوصول إلى كسر `f` من الكمية: `t = (1/λ) · ln(N₀/N) = T₁/₂ · log₂(N₀/N)`.
- عدد «أنصاف الأعمار»: `n = log(N₀/N) / log 2`.

## 8) مثال محلول
**السؤال:** نويدة عمر نصفها 8 أيام. كم يوماً حتى يتبقى 1/1000 منها؟

**الحل:**
1. `N/N₀ = (1/2)^n` حيث n عدد أنصاف الأعمار.
2. نريد `(1/2)^n = 1/1000` ⇒ `2^n = 1000` ⇒ `n = log(1000)/log(2) = 3/0.301 = 9.97`.
3. `t = 9.97 × 8 = 79.7` يوماً ≈ **80 يوماً**.
4. تحقق سريع باللوغاريتم الطبيعي: `t = T½ · ln(1000)/ln2 = 8 × 6.908/0.693 = 79.7` ✓

**ملاحظة فيزيائية:** بعد 10 أنصاف أعمار يتبقى ≈0.1٪ فقط — هذه قاعدة عملية
تُستخدم في تقدير زمن التخزين الآمن للنفايات القصيرة العمر.

## 9) تطبيقات
- حساب زمن تفكك مصدر طبي قبل التخلص منه.
- تحويل بين النشاط وعدد الذرات.
- قراءة منحنيات المقاطع العرضية المرسومة على محور لوغاريتمي للطاقة.
- حساب عدد طبقات القيمة النصفية في التدريع: `n = log(I₀/I)/log 2`.

## 10) أخطاء شائعة
1. `log(a+b) ≠ log a + log b` — خطأ قاتل متكرر.
2. الخلط بين `ln` و`log₁₀` (الفرق معامل 2.3026).
3. نسيان الإشارة السالبة في `e^(−λt)` فتخرج الكمية متضخمة بدل متضائلة.
4. كتابة `10^-3` في الآلة الحاسبة بلا أقواس في سياق أطول.
5. الظن أن `2^n = 1000` تعني `n = 500`.

اكتب سكربتاً يرسم `N(t)/N₀` من 0 إلى 10 أنصاف أعمار على محورين:
خطّي وشبه لوغاريتمي (log للمحور الصادي). لاحظ كيف يتحول المنحنى الأُسّي
إلى **خط مستقيم** — هذه حيلة ستستخدمها في كل تحليل اضمحلال لاحقاً.
