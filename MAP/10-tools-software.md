## 1) المكدّس البرمجي الأساسي (لكل المسارات)

| الطبقة | الأدوات | لماذا |
|---|---|---|
| لغة | **Python 3** | لغة العلوم النووية الفعلية اليوم (تحليل، محاكاة، أتمتة) |
| حساب علمي | **NumPy, SciPy, SymPy** | مصفوفات، ODE، ملاءمة، تكامل، تفاضل رمزي |
| رسوم | **Matplotlib** (+Plotly للتفاعلي) | أطياف، منحنيات اضمحلال، خرائط فيض |
| بيانات | **pandas, h5py, xarray** | جداول القياس، مخرجات المحاكاة |
| بيئة | **Jupyter, venv/conda, Git** | تكرارية (X.19) وإعادة إنتاج |
| أداء | **Numba, Cython, MPI4Py, OpenMP** | تسريع الحلقات الكثيفة |

**الترتيب المقترح:** `cs.python` → `cs.numpy` → `cs.data` → `math.mc` → `cs.uq` → `cs.vv`.

## 2) أكواد انتقال الجسيمات (Radiation Transport)

| الأداة | النوع | الرخصة/الجهة | الاستخدام الأكاديمي |
|---|---|---|---|
| **OpenMC** | مونتي كارلو نيوتروني/فوتوني، بايثون/ C++ | مفتوح المصدر (MIT) — تطوير مجتمعي وأكاديمي | من أفضل نقاط البداية: نماذج قلب، حرجية، تدريع، تكامل مع بيانات ENDF |
| **Serpent 2** | مونتي كارلو (تطوير مستمر) | VTT فنلندا — رخصة بحثية/غير تجارية | نيوترونيات القلب وحرق الوقود؛ شائع في الأبحاث |
| **MCNP** | مونتي كارلو مرجعي | LANL (توزيع عبر RSICC) | المعيار المرجعي في مقارنات كثيرة |
| **Geant4** | منصة C++ لانتقال الجسيمات | مفتوحة المصدر (CERN وتعاون دولي) | فيزياء الكواشف، الطب، الفضاء، فيزياء الجسيمات |
| **FLUKA** | انتقال وحزم | INFN — رخصة بحثية | تدريع، مصادر، حماية، dosimetry |
| **PHITS** | انتقال متعدد الجسيمات | JAEA (اليابان) — رخصة | تصميم التدريع، الفضاء، الطب |
| **SCALE/ORIGEN** | نظام حساب نووي متكامل | ORNL (RSICC) | حرق الوقود، مخزون النويدات، الحرجية |
| **NJOY** | معالجة البيانات النووية | LANL | تحويل ENDF إلى مكتبات مجموعات (GROUPR, THERMR…) |

**ممارسة إلزامية:** أي نتيجة مونتي كارلو تُعلن مع **عدد التاريخ، الانحراف المعياري،
ونتيجة اختبار تقارب**. النتيجة بلا عدم يقين ليست نتيجة.

## 6) أدوات الاندماج والبلازما

**ملاحظة أمان/سياسة:** أكواد النقل والحرق والتصميم المستخدمة في برامج الاندماج تخضع
لقيود تصدير/توزيع في بلدان عديدة؛ استخدم البدائل المفتوحة للتعلّم (أكواد MHD تعليمية،
نماذج صفرية-البعد، أدوات المجتمع المفتوحة) ولا تتعامل مع بيانات منشآت محكومة.

- أدوات مفتوحة للتعلّم: نماذج 0-D لشرط لوسون وتوازن الطاقة (اكتبها بنفسك — مشروع ممتاز)،
  مكتبات Python للبلازما، محاكيات MHD التعليمية.
- الأكواد المؤسسية (TRANSP، وأكواد الجيروكينتيك، وأكواد تصميم الملفات): تُستخدم في
  بيئات بحثية مرخّصة فقط.
