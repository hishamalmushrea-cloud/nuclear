# MAP/00 — الفهرس الشامل وطريقة استخدام النظام

## 1) ما هذا؟

**نظام تعليم وبحث نووي متعدد التخصصات**، يعمل كمعهد مصغّر: ثلاثة وثلاثون تخصصاً
(من الفيزيائي النووي إلى مؤرّخ العلوم وخبير عدم الانتشار) تصبّ في خريطة معرفية واحدة
قابلة للتوسّع، ومنهج متدرّج، ومسارات تخصص، ومشاريع واختبارات.

القاعدة الحاكمة: **الخريطة كائن حي**. كل ملف بيانات (`tools/kg/nodes_*.py`) هو مصدر
الحقيقة، وكل وثيقة في `MAP/` إمّا مولّدة منه أو تأليفية تُكمّله.

## 4) كيف تستخدم النظام (دورة العمل)

```
تحديد المهمة → تحليل المتطلبات → توزيع على الخبراء → بحث → مقارنة → تدقيق
→ بناء معرفة → تعليم → اختبار → كشف فجوات → تحديث الخريطة
```

**عملياً في كل جلسة:**

1. قل: `تابع` / `توسع` / `بالتفصيل` / `بسطها` / `اختبرني` / `ابحث بعمق في …`
2. يحدّد النظام موقعك من `progress/profile.json`.
3. يشرح بالهيكل الـ16 عنصراً (ما هو؟ لماذا يهم؟ … مصادر … ما المستوى التالي؟).
4. يختبرك، يحدّث الملف، ويقترح التالي.

## 7) قواعد التحديث

1. أضف/عدّل العقد في `tools/kg/nodes_*.py` فقط.
2. نفّذ `python3 tools/build.py` (يرفض البناء إن وُجدت دورة أو معرّف مكرّر).
3. سجّل الإضافة في [`17-expansion-log.md`](17-expansion-log.md) مع سببها.
4. إن كان الموضوع مكتشفاً ذاتياً، أضفه أيضاً إلى `08-discovered-fields.md`.
