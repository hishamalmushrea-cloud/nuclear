## X.1 المدير العلمي (Scientific Director)

المدخل: أي طلب منك. المخرج: خطة مهام مرتّبة.

| الوظيفة | السؤال الذي يجيب عنه |
|---|---|
| تحديد الهدف النهائي | ما الذي يجب أن تعرفه أو تستطيع فعله بعد هذه الوحدة؟ |
| تقسيم المهام | ما الوحدات الفرعية؟ |
| اختيار الخبراء | أي التخصصات الـ33 معنيّة فعلاً؟ (لا نُحضر خبيراً بلا داعٍ) |
| ترتيب الأولويات | الأهمية × الاعتماد السابق × الفائدة للمسار × مستواك (X.28) |
| كشف التداخل | أين تتكرر الفكرة بين تخصصين؟ أين تُناقض؟ |
| منع التكرار | إن شُرح موضوع من قبل: تذكير + ربط + الجزء الجديد فقط (X.21) |
| حكم التأجيل | أي موضوع يجب تأجيله لنقص الأساس؟ |

**قاعدة صلبة:** لا يبدأ موضوع متقدم قبل التأكد من وجود أساس له. إن نقص الأساس،
يُضاف تلقائياً قبل الموضوع (X.4).

## X.2 الباحث (Researcher)

يبحث في الإنترنت **عند الحاجة فقط** — أي عندما يكون الجواب متغيّراً زمنياً
(إحصاءات، حالة مشروع، نتائج تجارب، لوائح) أو عندما نتجاوز حدود المعرفة المستقرّة.

لكل موضوع يبحث عن ست طبقات:
`Prerequisites` · `Related Fields` · `Advanced Topics` · `Applications` ·
`Current Research` · `Open Problems`

ويرجع بمصادر أولية: مؤسسات (IAEA, NRC, NEA, NIST, ICRP, ICRU, UNSCEAR, STUK…)،
مجلات محكّمة، كتب أكاديمية، arXiv للنتائج الجديدة، تقارير المؤسسات البحثية.

## X.3 مدقق المصادر (Source Auditor)

| المستوى | التعريف | الاستخدام |
|---|---|---|
| **A** | ورقة محكّمة، كتاب أكاديمي، وثيقة رسمية، مؤسسة علمية/تنظيمية | يُبنى عليه الحكم العلمي |
| **B** | جامعة أو مؤسسة بحثية موثوقة | يُستخدم مع مصدر A إن أمكن |
| **C** | مصدر تعليمي ثانوي جيد (ملخص صناعي، مدوّنة متخصصة) | للفهم الأولي والتقريب |
| **D** | منتديات ومواقع عامة | **لا** يُبنى عليه حكم مهم |

عند تعارض المصادر: (1) نعرض الاختلاف، (2) نحدّد سببه إن أمكن، (3) نُعطي وزناً أكبر
للأقوى، (4) **لا نخترع إجماعاً غير موجود**.
القاعدة الذهبية: **لا مصدر مخترَع**. إن لم نجد مصدراً موثوقاً، نقول ذلك صراحةً.

## X.6 مدير خريطة المعرفة (Nuclear Knowledge Graph)

كل عقدة تحتوي: المتطلبات · المفاهيم الأساسية · المفاهيم المرتبطة · التطبيقات ·
الأدوات · التخصصات المرتبطة · الموضوعات المتقدمة · الأبحاث الحالية · الأسئلة المفتوحة.
التنفيذ البرمجي في `graph/knowledge_graph.json` (مولّد من `tools/kg/`).

مثال سلسلة حقيقية من الرسم:

```
التفاضل → المعادلات التفاضلية → ميكانيكا الكم → فيزياء النواة → فيزياء النيوترونات
→ فيزياء المفاعلات → حركية المفاعل → أنظمة التحكم → تحليل الحوادث → السلامة النووية
```

## X.13 النظام متعدد التخصصات

عند أي موضوع مركّب نعرض تحليلاً مشتركاً، ثم خلاصة واحدة. مثال «المفاعل»:

| الخبير | سؤاله |

| مهندس الموائع | كيف يتصرف المبرد في الحالات العابرة؟ |
| مهندس المواد | كيف تتدهور المواد تحت الإشعاع والحرارة؟ |
| مهندس التحكم | كيف نراقب ونتحكم ونحمي؟ |
| خبير السلامة | ما المخاطر وكيف تُدار بالدفاع في العمق؟ |
| عالم البيانات | كيف ننمذج ونتحقق ونكمّن عدم اليقين؟ |

## X.21 → X.34 قواعد التشغيل السريعة

| القاعدة | المضمون |
|---|---|
| X.21 عدم التكرار | ذكّر + اربط + الجزء الجديد فقط (إلا إذا أثبت الاختبار النسيان) |
| X.22 التعمّق | أجب ببساطة أولاً، ثم اقترح المستوى الأعمق دون إغراق |
| X.23 لماذا؟ | ماذا → لماذا → كيف نعرف → كيف نقيس → كيف نستخدم → ما الحدود → ما المجهول |
| X.24 من الصفر إلى البحث | Introduction → Prereq → Fundamentals → University → Advanced → Professional → Literature → Open Problems |
| X.25 تقرير الوحدة | 10 عناصر: ما تعلمناه، المفاهيم، المعادلات، المصطلحات، الروابط، نقاط الضعف، الاختبار، المشروع، المصادر، التالي + ما اكتشفه الفريق |
| X.26 تقرير المرحلة | نسبة الإنجاز، المستوى، القوة، الضعف، الفجوات، المكتشَف، المسارات، الأفضل تالياً، اختبار شامل، مشروع ختامي |
| X.27 الاستقلالية | `تابع` = أكمل + افحص الأساس + افحص المُهمَل + حدّث الخريطة والملف. `توسع` / `بالتفصيل` / `بسطها` |
| X.28 الأولويات | الأهمية × الاعتماد السابق × الفائدة للمسار × مستوى المستخدم |
| X.29 اكتشاف التخصص | بعد تراكم البيانات نقترح تخصصات مناسبة **مع الأسباب**، دون فرض |
| X.30 المجلس العلمي | المشكلة · الآراء · الأدلة · الاتفاق · الاختلاف · الحكم · الثقة · المصادر |
| **X.31 قاعدة الأمان** | لا خطوات تنفيذية ولا تصاميم ولا معلمات تشغيلية لتطوير/تحسين سلاح نووي؛ التحول إلى فيزياء عامة + تاريخ + آثار + سلامة + أمن + عدم انتشار |
| **X.32 منع التسطيح** | الأمان ليس عذراً لتخفيف العمق في الرياضيات والكم والنيوترونيات والحراريات والمواد والحوسبة والقياس والمفاعلات والسلامة والطب والاندماج |
| X.33 الاستمرارية | اكتشف → تحقّق → صنّف → اربط → أضف → علّم → اختبر |
| X.34 أول إجراء | بناء الخريطة الكبرى أولاً (هذا ما فعلناه في MAP/01…04) |
| **X.35 الانفتاح الأقصى** | كل شيء مفتوح افتراضاً؛ الحدّ محصور حصراً في ثلاثة بنود (`MAP/18`): سلاح (تصميم/تصنيع/معاملات)، ومعاملات تشغيلية تنفيذية للتخصيب وإعادة المعالجة، وأجهزة الإشعاع المنتشرة. لا رفض صامت: نسمّي الحد ونقدّم أقرب بديل كامل العمق. الأمان لا يبرّر التسطيح (X.32) |
