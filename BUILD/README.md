# 🛠️ «كيف أصنع؟» — مشاريع حقيقية تبنيها بيدك

هذا القسم يجيب عن سؤالك: **«علّمني كيف أصنع وأعمل أشياء»**.
كل مشروع: **ماذا يعلّمك · المواد · الخطوات · ماذا ستلاحظ · كيف تخرج منه قياساً حقيقياً · السلامة والقانون.**

---

## ⚖️ ثلاث قواعد قبل أي مشروع

1. **القانون أولاً:** مصادر الإشعاع — حتى الصغيرة جداً منها — تخضع لتنظيم في أغلب الدول.
   استخدم فقط **مصادر مختومة ومعفاة قانونياً** (مثل شبكة مصباح الغاز المثورة، أو زجاج اليورانيوم،
   أو مصدر Am-241 المختوم داخل كاشف الدخان **دون فكه أبداً**). تحقّق من قوانين بلدك قبل الشراء أو الحيازة.
2. **السلامة قبل الفضول:** لا تفكّ مصدراً مختوماً · لا تطحنه · لا تحرقه · لا تأكل أو تشرب في مكان العمل ·
   اغسل يديك · خزّنه بعيداً عن الأطفال والحوامل · تخلّص منه عبر جهة مختصة لا في النفايات.
3. **القياس قبل الادعاء:** أي ملاحظة تصبح علماً فقط حين تكتبها: التاريخ، الزمن، المسافة، العدد،
   وعدم اليقين (`√N`). استخدم `progress/notebook-template.md`.

## الترتيب الذي أقترحه

```
03 (ابنِ محاكيك)  ──┐
                    ├──►  02 (المِكشاف: تأيّن حقيقي)  ──►  01 (غرفة السحاب)  ──►  04 (مشروع بيانات)
000/001/002 (الدروس)┘
```

ابدأ بـ **03** إن لم تكن قد برمجت من قبل: هو الذي يعطيك «أداة» تفكر بها.
ثم **02** لأنه يثبت أن الإشعاع يؤيّن الهواء بدون أي مصدر مشعّ.
ثم **01** — حيث ترى الجسيم فعلاً.
ثم **04** — حيث تصبح باحثاً يقرأ بيانات حقيقية وينشر تقريره.

## تنويه

هذه المشاريع **تعليمية**. أي عمل بمصادر مشعة أو أجهزة جهد عالٍ أو مواد كيميائية
هو مسؤوليتك الشخصية ويجب أن يتم وفق قوانين بلدك، وبإشراف مختص إن لزم.
هذا المستودع لا يقدّم استشارة قانونية أو تنظيمية.
