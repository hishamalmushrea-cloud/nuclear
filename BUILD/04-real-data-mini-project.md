## 1) اختر سؤالاً صغيراً ومحدّداً
**أسئلة جاهزة يمكنك البدء بها الآن** (كلها قابلة للحل ببيانات عامة):

| # | السؤال | البيانات | الأدوات |
|---|---|---|---|
| 1 | هل تتفق قيم عمر النصف المنشورة لنويدة معينة بين قاعدتي بيانات؟ | ENSDF / NuDat / LiveChart | Python |
| 2 | كيف يتغير مقطع الامتصاص الحراري عبر الجدول الدوري؟ | ENDF/B عبر JANIS أو NNDC | Python + رسم |
| 3 | ما توزيع أعمار النصف للنويدات المستقرة مقابل المشعة؟ | LiveChart (تنزيل CSV) | pandas |
| 4 | كم تبلغ نسبة النويدات التي تتحلل بألفا مقابل بيتا في منطقة كتل معينة؟ | ENSDF | Python |
| 5 | كيف يتغير عدد المفاعلات العاملة عالمياً عبر الزمن؟ | IAEA PRIS | pandas + رسم |
| 6 | ما العلاقة بين رقم الكتلة وطاقة الارتباط لكل نيوكليون؟ | جداول الكتل (AME/Nubase) | Python + رسم |

**قاعدة السؤال الجيد:** محدّد (نويدة/مجال/فترة) + قابل للقياس + بياناته متاحة + له معنى.

## 2) اجمع البيانات من مصدر Level-A
| المصدر | ماذا يعطيك | الرابط |
|---|---|---|
| **IAEA LiveChart** | خصائص النويدات، مخططات التحلل، تنزيل | https://nds.iaea.org/ |
| **NNDC NuDat** | مستويات الطاقة، التحلل، NuDat-3 | https://www.nndc.bnl.gov/ |
| **EXFOR** | بيانات تجريبية للتفاعلات (21 ألف تجربة+) | عبر IAEA NDS |
| **ENDF/B, JEFF, JENDL** | مكتبات مقيّمة للمقاطع العرضية | NNDC / NEA |
| **JANIS** (NEA) | تصفّح ورسم المكتبات وEXFOR معاً | https://www.oecd-nea.org/janis/ |
| **IAEA PRIS** | مفاعلات العالم: العدد، القدرة، العمر | https://pris.iaea.org/pris/ |

**قاعدة مدقق المصادر (X.3):** سجّل لكل رقم: المصدر + **تاريخ الالتقاط** + الإصدار.
الأرقام الإدارية (عدد المفاعلات) تتغير أسبوعياً — والفرق بين 413 و416 سببه التاريخ لا الخطأ.

## 4) حلّل
مثال مصغّر — منحنى طاقة الارتباط (أشهر رسم في الفيزياء النووية):
```python
import matplotlib.pyplot as plt
plt.plot(df["A"], df["binding_energy_per_nucleon"])
plt.xlabel("عدد الكتلة A"); plt.ylabel("طاقة الارتباط/نيوكليون (MeV)")
plt.axvline(56, ls="--")     # الحديد: القمة
plt.show()
```
**السؤال الذي يجب أن تجيب عنه:** لماذا تبلغ القمة عند الحديد؟
ولماذا يطلق **الانشطار** طاقة للثقيلة و**الاندماج** طاقة للخفيفة؟ (نفس المنحنى يجيب الاثنين.)
