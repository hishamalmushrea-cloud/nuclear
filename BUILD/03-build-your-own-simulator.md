## 1) الخطة (7 خطوات)
```

2. ابنِ توزيعاً إحصائياً             → بواسون

5. ارسم النتيجة                     → matplotlib أو رسم نصي
6. استخرج الحقيقة من الضجيج          → مربعات صغرى

```

## 2) الخطوة 1–2: إحصاء بواسون (قلب كل قياس نووي)
العدّ النووي ليس «رقيماً ثابتاً» بل **عينة من توزيع بواسون**: معدله `λ` وانحرافه `√λ`.

```python
# poisson.py — اكتبه بنفسك ولا تستورد النسخة الجاهزة أول مرة
import math, random

def poisson(lam):
    """Knuth: ولّد أعداداً عشوائية واضربها حتى تنزل عن e^(-λ)."""
    if lam <= 0:
        return 0
    L = math.exp(-lam)
    k, p = 0, 1.0
    while True:
        p *= random.random()
        if p <= L:
            return k
        k += 1

# جرّب: نفس المعدل، نتائج مختلفة
for _ in range(10):
    print(poisson(20), end="  ")
```
**ماذا تلاحظ؟** النتائج تتذبذب حول 20. هذا هو «الضجيج» الذي لن يختفي أبداً.
**اكتبه في دفترك:** `σ = √N`، و`عدم اليقين النسبي = 1/√N`.

## 4) الخطوة 4: اجمعهما → «تجربة»
```python
def experiment(half_life=60.0, n_points=10, dt=10.0, A0=300.0, background=0.5, seed=42):
    import random, math
    random.seed(seed)
    lam = math.log(2) / half_life
    rows = []
    for i in range(n_points):
        t = i * dt * 6                    # نقيس كل دقيقة
        exp_counts = A0 * math.exp(-lam * t) * dt + background * dt
        counts = poisson(exp_counts)      # ← هنا صارت «تجربة»
        rows.append((t, counts))
    return rows

for t, c in experiment():
    print(f"{t:6.0f} ث → {c:5d} نبضة  ±{math.sqrt(c):.1f}")
```

## 6) الخطوة 6: استخرج الحقيقة (مربعات صغرى يدوياً)
المطلوب: من بيانات مشوّشة، استخرج `λ`.
```python
import math
def fit_half_life(rows):
    xs, ys = [], []
    for t, c in rows:
        if c > 0:
            xs.append(t); ys.append(math.log(c))     # خطّيّة
    n = len(xs); mx = sum(xs)/n; my = sum(ys)/n
    slope = sum((x-mx)*(y-my) for x, y in zip(xs, ys)) / sum((x-mx)**2 for x in xs)
    return -slope, math.log(2)/(-slope)              # λ ثم T½

lam_fit, t_half = fit_half_life(experiment(seed=1))
print(f"التقدير: T½ = {t_half:.1f} ث (الحقيقي: 60)")
```
**جرّب بذوراً مختلفة (seed=2,3,4…):** كم يتغير التقدير؟ هذا هو **عدم يقين القياس** الذي يجب أن تعلنه.

## 7) الخطوة 7: أعلن عدم اليقين (الفرق بين هاوٍ وباحث)
```python
print(f"T½ = {t_half:.1f} ± {abs(t_half-60):.1f} ث (انحراف عن القيمة الحقيقية في المحاكاة)")
```
في العالم الحقيقي لا تعرف القيمة الحقيقية، فتقدّر عدم اليقين من:
- عدد النبضات (`√N`)،
- جودة الملاءمة (`χ²`)،
- تكرار القياس (الانحراف المعياري للمتوسط).

## 8) الآن «حاكِ أي شيء» — خوارزمية التعميم
لكل ظاهرة تريد محاكاتها، املأ هذه الخانة:
| السؤال | مثال: الاضمحلال | مثال: التدريع | مثال: المفاعل |
|---|---|---|---|
| ما الكمية المتغيّرة؟ | عدد النوى | الشدة | القدرة |
| ما القانون؟ | `e^(−λt)` | `e^(−μx)` | معادلات النقطة |
| ما مصدر العشوائية؟ | بواسون | بواسون | بواسون + اضطراب |
| ما المجهول الذي تريد استخراجه؟ | T½ | μ | ρ |
| كيف تتحقق؟ | حل تحليلي | قيمة مرجعية | حالة مستقرة |
